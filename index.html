FoodVerse

Java · Spring Boot · MySQL · Redis · Kafka · Docker · Kubernetes

A modular food delivery backend covering the full order lifecycle — users, restaurants, menus, carts, orders, payments, delivery, and admin operations — built as a set of cooperating Spring Boot services rather than one monolith.

usersrestaurantsmenuscartsorderspaymentsdeliveryadmin
  • 25+ REST APIs built with Spring MVC, Spring Data JPA and Hibernate — DTOs, validation, pagination, filtering, centralized exception handling.
  • JWT authentication with role-based access control for customers, restaurant owners, delivery partners and admins.
  • Redis caching on frequently accessed restaurant and menu data to cut database load.
  • Kafka-driven events for order, payment, restaurant and delivery flows.
  • Razorpay integration — payment-order creation, verification, and idempotent order processing.
  • Resilience4j circuit breaker, retry, rate limiter and fallback for fault-tolerant operations.
  • Swagger/OpenAPI docs, Postman-tested endpoints, and Actuator health checks with structured logging.
  • Containerized with Docker, with Kubernetes configs prepared for deployment and scaling.
